# Trabajo Práctico Integrador - El Sabueso Feliz

Proyecto Django para una veterinaria con documentación estructurada para diseño y desarrollo.

## Estructura del repositorio

- `README.md`: Guía de instalación y uso.
- `requirements.txt`: Dependencias del proyecto.
- `docs/`: Documentación y artefactos de diseño.
  - `docs/uml/`: Diagrama UML de clases y material relacionado.
  - `docs/er/`: Diagrama ER y material relacionado.
  - `docs/diagrams/`: Imágenes y exportaciones de los diagramas.
