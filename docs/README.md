# Documentación del proyecto

Este directorio contiene los documentos de diseño requeridos por el trabajo práctico integrador.

## Carpetas principales

- `docs/uml/`: Diagrama UML de clases y archivos relacionados.
- `docs/er/`: Diagrama ER y archivos relacionados.
- `docs/diagrams/`: Exportaciones de los diagramas en imagen o PDF.
