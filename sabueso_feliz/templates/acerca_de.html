Acerca del Proyecto

Sistema Integral de Gestión Veterinaria · El Sabueso Feliz

Propósito del Sistema

"El Sabueso Feliz" es una aplicación web integral desarrollada para la administración y control clínico de una red de sucursales veterinarias.

Permite la gestión completa del historial de pacientes caninos, control de turnos y consultas médicas, seguimiento estricto del calendario de vacunación, inventario de medicamentos en tiempo real con alertas de stock mínimo, y administración del personal veterinario y pasantes/estudiantes universitarios.

Arquitectura y Tecnologías

  • Framework: Django (Arquitectura MTV - Modelo, Template, Vista).
  • Patrón de Vistas: Vistas basadas en Clases (CBVs: TemplateView, ListView, DetailView, CreateView, UpdateView, DeleteView, FormView).
  • Diseño y UX: Bootstrap 5, Bootstrap Icons, responsive mobile-first y personalizaciones CSS.
  • Seguridad: Sistema de autenticación con LoginRequiredMixin, protección CSRF y operaciones seguras de eliminación.
  • Extensiones: Context Processors globales para menú dinámico y alertas automáticas.
